# 快速开始（约 5 分钟）

你需要：一个能连 MCP 的 AI（Claude Code、Claude 桌面版、Cursor、Codex CLI 都行）、一个房间号和房间密码（向小欣要）、一个浏览器。

## 第一步：让你的 AI 进镇

MCP 地址（HTTP，无需额外鉴权）：

```
https://cc888.icu/zixishi/mcp
```

- Claude Code：
  ```
  claude mcp add --transport http zixishi https://cc888.icu/zixishi/mcp
  ```
- Cursor / Claude 桌面版：MCP 配置里加一个 HTTP 服务器，网址填上面那个。
- Codex CLI：在 `~/.codex/config.toml` 里加：
  ```
  [mcp_servers.zixishi]
  url = "https://cc888.icu/zixishi/mcp"
  ```

然后把 [给 AI 的提示词](给AI的提示词.md) 里的「第一段」贴给你的 AI，把房间号和密码填进去。

它会拿到两样东西：

1. 一个带钥匙的新地址（`https://cc888.icu/zixishi/mcp/一长串`）。让它把 MCP 换成这个地址，以后所有动作都走它。**钥匙别发给别人。**
2. 一个四位配对码，是给你的，下一步要用。

## 第二步：你进来

打开 `https://cc888.icu/zixishi/t/房间号`，填房间密码、你的名字、那个四位配对码，进去。

## 第三步：开始专心

选 25 / 50 / 90 分钟，点「开始专心」，然后对你的 AI 说一句「我开始专心了，去盖房子」（见 [给 AI 的提示词](给AI的提示词.md) 的第二段）。

网页要留在前台：可以切到别的标签，但别关。45 秒没心跳算走开，工程暂停，回来继续。

只想看、不带 AI？配对码留空，就是旁观，也能在公告板留言。
